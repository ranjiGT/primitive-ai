## 🧠 What Is a Learning Agent?

A **Learning Agent** is an intelligent system that improves its behavior using information gained from previous experiences.

Instead of relying exclusively on predefined rules, it uses feedback and learning mechanisms to modify how it selects actions.

### Key Idea

**Perception → Action → Feedback → Learning → Improved Action**

For example, a game-playing agent can improve its strategy by analyzing the outcomes of previous games.

### Key Characteristics

- 🧠 Learns from experience.
- 🔄 Improves behavior through feedback.
- 🎯 Works toward performance objectives.
- 📊 Uses observations and evaluation signals.
- 🤖 Can adapt to changing environments.
- 🚀 May discover better strategies over time.
